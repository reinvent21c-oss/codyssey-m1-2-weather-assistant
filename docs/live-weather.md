무료 공개 API는 비상업적 이용 한정. 교육용 프로젝트는 약관 예시에 포함되지만 광고·구독·상업 서비스로 전환할 때는 유료 이용 조건 재검토가 필요함. 무료 호출 한도는 분당 600회, 시간당 5,000회, 일일 10,000회 미만이며 월 300,000회 표기도 확인함. 데이터의 CC BY 4.0 라이선스와 무료 API 접근의 비상업적 조건은 별개임.

표시 화면에 Open-Meteo 출처 링크, CC BY 4.0 링크와 규칙 기반 추천으로 가공했다는 안내를 함께 제공함. 모델 발표 시각은 일반 Forecast 응답에서 확인하지 못하므로 null로 두며, 서버 조회 시각을 발표/갱신 시각으로 표현하지 않음. 제공자의 예보 정확성과 연속 가용성은 보장되지 않음.

## 날짜·단위·추천 규칙

- 오늘 날짜는 서버 OS 시간대가 아닌 서울 시간으로 계산. 현재 서울은 DST 없는 UTC+09:00이며 Windows tzdata 설치 없이 명명된 고정 오프셋을 사용함. 과거 시간대 변환 기능은 제공하지 않음.
- 현재 시각 이전의 선택은 거부. 정각은 해당 시간, 정각 사이의 분은 다음 정각으로 매핑. 예: 10:30 → 11:00(30분 차이), 오늘 23:30 → 다음 날 00:00. 선택 날짜는 항상 오늘이며 최대 차이는 59분. 내일의 임의 시각 선택은 지원하지 않음.
- 제공자 요청 범위는 서울 기준 오늘과 다음 날. 응답 timezone/UTC offset, 시간 배열 순서·중복·형식, 필드 길이, 단위와 유한 숫자 범위를 검증. bool·문자열·null·NaN·Infinity·결측 필드를 0으로 바꾸지 않음.
- 기온 °C, 강수확률 %, 예보 강수량 mm, 풍속 m/s 네 값이 모두 유효할 때만 추천. 미확인 값이 하나라도 있으면 전체 추천을 확인 불가로 처리하는 보수적 정책임.
- 강수확률과 강수량은 해당 정각 **이전 한 시간**의 예측값. 실제 관측 강수량이 아님. 기온·풍속은 해당 정각의 값. 한 시점/구간만 다루므로 외출 전체 시간의 날씨를 보장하지 않음.
- 기온별 기본 복장 구간: 5°C 미만 / 12°C 미만 / 20°C 미만 / 28°C 미만 / 그 이상. 강수확률 40% 이상 또는 예보 강수량 0 초과면 우산 권장. 10 m/s 이상이면 바람막이와 강풍 시 우산 주의 안내. 이는 브리의 일반 준비 규칙이며 의학·재난 판단 기준이 아님.

## 호출·캐시·실패 경계

- 서버 애플리케이션 인스턴스별 공유 10분 메모리 캐시와 잠금으로 동시 중복 호출 방지. 날짜 변경 시 새 날짜 조회. HTTP 각 단계 타임아웃 5초, 자동 재시도 없음, 리다이렉트와 환경 프록시 사용 안 함.
- 실패 뒤 10분 재시도 억제. 캐시 만료·날짜 변경 후 실패하면 오래된 값을 대신 보여주지 않음. 선택 시각 변경·재조회·실패 때 UI의 이전 추천도 제거.
- 캐시 기준 통상 인스턴스당 하루 약 144회와 날짜 변경 시 추가 조회 정도. 프로세스 재시작·다중 worker·복제본에는 공유되지 않으므로 제공자 계정/전체 IP 쿼터의 절대 상한은 아님. 규모 확장 전 분산 캐시/전역 제한 검토 필요.
- 호출 URL·서울 좌표 고정, 인증 헤더나 사용자 입력 URL을 제공자에 전달하지 않음. 제공자 오류 내용은 화면에 노출하지 않음.
- 실패·빈 결과·미지원 시각 응답은 HTTP 200의 `status: unavailable`, null 기상/추천 필드와 한국어 안내. 인증 실패는 기존 401 유지.

## GPT 연결

외출 추천 성공 후 브라우저는 선택한 aware timestamp(`outing_at`)만 전송. 서버가 당일 날짜·분 단위 시각을 확인하고 **유효한 서버 캐시만** 읽어서 전달함. 클라이언트 기상 수치 입력은 스키마에서 금지. 채팅에서는 새로운 날씨 HTTP 요청을 만들지 않으며, 캐시 없음/만료/다른 날짜는 unavailable Context로 전달함. Context 미전송 시에도 현재 날씨와 이전 대화의 날씨를 추측하지 않도록 기존 프롬프트를 보강함. GPT 제한·관리자/평가자 권한·저장 흐름은 유지.
